# KORI Portfolio + Journal

포트폴리오와 회고 블로그를 한곳에서 운영하는 개인 사이트입니다.

## 글 쓰는 방법

GitHub 저장소를 Pages CMS에 연결한 뒤 `Journal`에서 새 글을 작성합니다. `임시 저장`을 끄고 저장하면 사이트에 공개됩니다.

## 수정할 곳

- 이름·소개·이메일: `src/content/settings/site.json`
- 회고 글: `src/content/journal/`
- 포트폴리오: `src/content/work/`
- 이미지: `public/images/`

## 시작하기

```sh
pnpm install
pnpm dev
```
